# Internationalization

`Zigote.UI.Localizations` translates and formats an app for many languages. It has three parts:

1. **Declare** translations as a `LocalizationBundle` of per-locale `LocalizationCatalog`s, in code or loaded from JSON/ARB files.
2. **Provide** them by wrapping a subtree (usually the whole `Home`) in a `LocalizationsScope`.
3. **Consume** them from any widget with `context.Tr("key", …)` or `LocalizedText`, and switch language at runtime with `context.SetLocale(…)`. Widgets that read a translation rebuild automatically, just as they do for a theme change.

The package references only `Zigote.UI`. Its core (locales, CLDR plural rules, ICU message formatting, number and date formatting) is headless and unit-tested.

## A live language switch

Switch between English, Spanish, Russian and Arabic. Watch the plural forms change (Russian has four), the currency and date formats follow the locale, and the whole layout mirror for Arabic.

```csharp run height=360
static class Strings
{
    public static readonly LocalizationBundle Bundle = new(
        new LocalizationCatalog(Locale.En) {
            ["title"] = "Shopping cart",
            ["greeting"] = "Welcome back, {name}!",
            ["items"] = "{count, plural, =0 {Your cart is empty} one {# item in your cart} other {# items in your cart}}",
            ["add"] = "Add item",
            ["total"] = "Total: {sum}",
        },
        new LocalizationCatalog(Locale.Es) {
            ["title"] = "Carrito",
            ["greeting"] = "¡Hola de nuevo, {name}!",
            ["items"] = "{count, plural, =0 {Tu carrito está vacío} one {# artículo en tu carrito} other {# artículos en tu carrito}}",
            ["add"] = "Añadir",
            ["total"] = "Total: {sum}",
        },
        new LocalizationCatalog(Locale.Ru) {
            ["title"] = "Корзина",
            ["greeting"] = "С возвращением, {name}!",
            ["items"] = "{count, plural, =0 {Корзина пуста} one {# товар в корзине} few {# товара в корзине} many {# товаров в корзине} other {# товара в корзине}}",
            ["add"] = "Добавить",
            ["total"] = "Итого: {sum}",
        },
        new LocalizationCatalog(Locale.Ar) {
            ["title"] = "سلة التسوق",
            ["greeting"] = "مرحبًا بعودتك يا {name}!",
            ["items"] = "{count, plural, =0 {السلة فارغة} one {منتج واحد} two {منتجان} few {# منتجات} many {# منتجًا} other {# منتج}}",
            ["add"] = "إضافة",
            ["total"] = "المجموع: {sum}",
        }) { FallbackLocale = Locale.En };
}

sealed class Cart : ComposedWidget
{
    private readonly Signal<int> _count = new(0);

    protected override Widget Build(BuildContext context)
    {
        var theme = ThemeProvider.Of(context);
        Locale[] locales = [Locale.En, Locale.Es, Locale.Ru, Locale.Ar];
        return new Padding(EdgeInsets.All(20), new Column(spacing: 12, crossAxisAlignment: CrossAxisAlignment.Start, children: [
            // A locale switch rebuilds this widget, so the toggle is told which one is active.
            new AdwToggleGroup(labels: ["English", "Español", "Русский", "العربية"],
                active: Array.IndexOf(locales, context.LocaleOf()),
                onActive: i => context.SetLocale(locales[i])),
            new LocalizedText("title") { FontSize = 22, FontWeight = FontWeight.Bold },
            new Label(context.Tr("greeting", ("name", "Ada")), fontSize: 15),
            new Watch(() => new Label(context.Tr("items", ("count", _count.Value)), fontSize: 15)),
            new Watch(() => new Label(
                context.Tr("total", ("sum", context.FormatCurrency(_count.Value * 19.99m, currencyCode: "EUR"))) + "  ·  " +
                context.FormatDate(new DateTime(2026, 10, 19)),
                fontSize: 13, color: theme.TextSecondary)),
            new Row(spacing: 8, children: [
                new AdwButton(label: context.Tr("add"), onPressed: () => _count.Value++) { Style = AdwButtonStyle.Suggested },
                new AdwButton(label: "−", onPressed: () => _count.Value = Math.Max(0, _count.Value - 1)),
            ]),
        ]));
    }
}

class Demo : ComposedWidget
{
    protected override Widget Build(BuildContext context) => new LocalizationsScope {
        Bundle = Strings.Bundle,
        SupportedLocales = { Locale.En, Locale.Es, Locale.Ru, Locale.Ar },
        InitialLocale = Locale.En,
        Child = new Cart(),
    };
}
```

Try adding `Locale.Ja` with a Japanese catalog. Japanese has no plural forms, so `other` covers every count.

> Read translations in `Build` or inside a `Watch` builder, so the widget rebuilds when the locale changes. In an event handler, do the *action* (`context.SetLocale(…)`, which finds the scope this widget sits under) and let the rebuild produce the new text.

## Message format

Messages use an ICU subset. A malformed template never crashes the UI; it falls back to its raw text.

| Form | Example |
|---|---|
| Placeholder | `Hello, {name}!` |
| Plural | `{n, plural, =0 {none} one {# item} other {# items}}` |
| Plural offset | `{n, plural, offset:1 one {you and # other} other {you and # others}}` |
| Ordinal | `{pos, selectordinal, one {#st} two {#nd} few {#rd} other {#th}}` |
| Select | `{g, select, male {He} female {She} other {They}}` |
| Typed number | `{price, number, currency}`, `{r, number, percent}`, `{n, number, integer}` |
| Typed date/time | `{d, date, medium}`, `{t, time, short}` |
| Escaping | `it''s` → `it's`, `'{'literal'}'` → `{literal}` |

Plural categories follow the Unicode CLDR rules. Germanic, Romance, Slavic, Arabic, Hebrew, Baltic, Romanian, Indic and the no-plural languages are exact; unlisted languages default to English's `one`/`other` split.

## Formatting numbers and dates

Never build a number or date string with `ToString()` in UI code: it uses the thread's culture, not the user's chosen locale. Use the context helpers, which follow the active locale. Pass a currency code: a language-only locale such as `en` has no country, so it has no currency of its own.

```csharp
context.FormatNumber(1234.5);            // 1,234.5  ·  1.234,5  ·  1 234,5
context.FormatPercent(0.42);             // 42%  ·  42 %
context.FormatCurrency(19.99m, "EUR");   // €19.99  ·  19,99 €  (symbol placement follows the locale)
context.FormatDate(DateTime.Today);      // locale's medium date
context.FormatTime(DateTime.Now);        // 14:05  ·  2:05 PM
```

## Right-to-left

Each `Locale` knows its `TextDirection`. `LocalizationsScope` installs a `Directionality` for its subtree, so `Row`, `Padding` with `EdgeInsetsDirectional`, `RichText` and the Adwaita controls mirror themselves for Arabic, Hebrew and Persian. The shaper reorders mixed-direction text within a line. In your own hand-written widgets, read `Directionality.Of(context)` and mirror the layout yourself; the base paint path does not flip coordinates automatically.

> Prefer `EdgeInsetsDirectional.Only(start: …, end: …)` over `left`/`right` for anything that should mirror.

## Loading translations from files

Keep translations out of code so translators can work on them:

```csharp
// Flat per-locale files, ARB-compatible (@metadata keys are ignored):
var en = LocalizationJson.LoadCatalog(File.ReadAllText("l10n/en.arb"), Locale.En);

// One nested file for every locale:  { "en": { "hi": "Hello" }, "es": { "hi": "Hola" } }
var bundle = LocalizationJson.LoadBundle(File.ReadAllText("l10n/all.json"));
```

For compile-time safety, register a typed `LocalizationsDelegate<T>` (for example, a class generated from your ARB files) and read it with `Localizations.Of<T>(context)`. The string bundle and typed delegates coexist in one scope.

## Checklist

- **Every user-visible string goes through `Tr`**, including button labels, tooltips, accessibility labels and error messages.
- **Never concatenate translated fragments.** Word order differs between languages; put the whole sentence in one message with placeholders.
- **Use plural and select forms**, not `count == 1 ? … : …`. Many languages have more than two plural forms.
- **Leave room.** German and Russian text often runs 30% longer than English. Test with long strings and avoid fixed widths around text.
- **Test RTL early.** Switch to Arabic during development, not after release.
- Use the inspect protocol's `locale` verb (or the MCP `set_locale` tool) to switch a running app's language from tests.
